# Current migration compromises

Requested by Elliot: keep the remaining costs visible, not a history of resolved review findings.
[ARCH](../../ARCH.md) explains assembly, [the roadmap](../reloadable-core-migration-roadmap.md) owns
unfinished scope, and [the live record](interaction-lifecycle-live-smoke.md) owns exact-build evidence.

| Compromise | Current consequence / next step |
| --- | --- |
| Frozen bodies and facets | Device, Session, Browser and other remaining families still use inherited policy. Delete their aliases, inbox callers and providers when each complete action/feedback slice migrates. Facet/claim correspondence still needs [bidirectional validation](../findings/stable-facet-claim-coupling.md). |
| One temporary page | One replaceable owner has an exact return token. Different buttons retain their established latch/return rules; a stack would be a product change. |
| Finite authored compositions | Pages compose declared Note/Drum/Session/VS backgrounds. There is no dynamic plugin/configuration loader or arbitrary hardware callback wiring. |
| Independently sampled domains | Parameter and track/project observations can arrive separately. Identity joins must reject contradictory data; a more coherent publication model could reduce repeated joins. |
| Movable target windows | Cancellation ends offscreen editing, but cannot manufacture Device identity or an actuator that remains addressable after external rebinding. Keep the [target constraints](../findings/parameter-target-proxy-coupling.md). |
| Snapback precision | Some inherited baselines/setters use controller-resolution values. Equal opposite encoder steps do not prove raw restoration; the [precision finding](../findings/snapback-v1-limitations.md) remains open. |
| Summed relative motion | Coalescing loses callback order and count. At a clamp, `+1,-1` can differ from net zero. Crossfade/MIDI-channel parity needs a shared input contract or explicit behavior decision. |
| Early action admission | A button whose LONG action changes page enters the parameter barrier at BEGIN; even its short tap can wait. Physical consumption remains separate from deferred host effects. |
| Session release | A submitted release can leave playback unchanged. Exact actuator reuse needs a [proved contract](session-launcher-location-design.md), not a guessed delay. |
| Native mapping lifecycle | Fixed learned endpoints are bounded and track-allocated; document identity, copied bindings, recycling and runtime labels retain their [specific limits](../findings/track-scoped-midi-learn-lifecycle.md). |

## Validation limits

The debugger observes transmitted display, lights and strip output plus subscribed host state.
It cannot establish audible behavior, physical feel or Bitwig's native learned-action execution.
Read-back and exact restoration must be checked separately from request submission.

Busy output can exceed the debugger's bounded trace capacity. Current smoke helpers use complete
records and fresh later samples; a missing required input/outcome fails that case. Helpers remain
in ignored build output, with durable evidence referenced from the live record. No generated
screenshots or offline tests stand in for an unperformed matched-build live check.
